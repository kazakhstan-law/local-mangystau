# Қарақия ауданы бойынша сайлау учаскелерін құру туралы

«Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі Конституциялық Заңының 23 бабының 1, 2 тармақтарына және «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін - өзі басқару туралы» 2001 жылғы 23 қаңтардағы № 148 - ІІ Қазақстан Республикасының Заңының 37 бабына сәйкес, Қарақия ауданының әкімі ШЕШІМ ЕТТІ:

<a id="p1"></a>

1. Қарақия ауданы әкімінің 25 сәуірдегі 2011 жылғы № 39 «Қарақия ауданы бойынша сайлау учаскелерін құру туралы» шешімінің күші жойылған деп танылсын (Нормативтік құқықтық акті мемлекеттік тіркеудің тізіліміне № 11-4-117 енгізілген, «Қарақия» газетінде 01 маусым 2011 жылы № 23/428/ ресми жарияланған).

<a id="p2"></a>

2. Қарақия ауданы бойынша сайлау учаскелері қосымшаға сәйкес құрылсын.

<a id="p3"></a>

3. Сайлау учаскелері Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі «Қазақстан Республикасындағы сайлау туралы» Конституциялық заңының 23 - бабының талаптары сақтала отырып бұқаралық ақпарат құралдары арқылы сайлаушыларға хабардар етілсін.

<a id="p4"></a>

4. Осы шешімнің орындалуын бақылау аудан әкімінің аппарат басшысы А.К.Абиловке жүктелсін.

<a id="p5"></a>

5. Шешім Әділет органдарында мемлекеттік тіркеуден өткен күнінен бастап күшіне және алғаш ресми жарияланған күннен бастап қолданысқа енгізіледі.
