# «Сәулет» мемлекеттік қазыналық кәсіпорын құру туралы

Қазақстан Республикасының 23 қазан 1993 жылғы Қазақстан Республикасындағы архитектура және қала құрылысы туралы"Заңында көосетілген заңды түрде нұсқалған тапсырмаларды жүзеге асыррулы қамтамасыз ету мақсатында, Қазақстан Республикасы Президентінің 19 маусым 1995 жылғы заң күші бар " Мемлекеттік кәсіпорындар туралы" №2335 жарлығына сәйкес, ШЕШІМ ЕТЕМІН:

<a id="p1"></a>

1. Жаңаөзен қалалық атқару комитеті жанындағы шаруашылық есептегі өндірістік-жобалау архитектуралық лщ жоспарлау бюросы мекемесі қайта құру жолымен "Сәулет” мемлекеттік қазыналық кәсіпорны болып қайта ұйымдастырылсын.

<a id="p2"></a>

2. "Сәулет” мемлекеттік қазыналық кәсіпорнының уәкілдік міндетін атқару қаланың бас архитекторына жүктелсін.

<a id="p3"></a>

3. "Сәулет" мемлекеттік қазыналық кәсіпорны жарғысы бекітілсін.

<a id="p4"></a>

4. ’’Сәулет” мемлекеттік қазыналық кәсіпорны директоры болып Құлбаев Ахмет Исмаилұлы тағайындалсын.

<a id="p5"></a>

5. ’’Сәуләт” мемлекеттік қазыналық кәсіпорнының құрылтайшы құжаттарын облыстық әділет баскармасынан мемлекеттік тіркеуден өткізу А.И. Құлбаевқа тапсырылсын.

**Қала әкімінің міндетін атқарушысы**

**Ж. Бабаханов**
